# StoQue+

App de controle de estoque criado com React, Vite e Supabase.

View your app in AI Studio: https://ai.studio/apps/77cfbf43-846b-4d18-bb4b-866a77772745

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Create a `.env.local` file with your Supabase credentials:
   `VITE_SUPABASE_URL=your-project-url`
   `VITE_SUPABASE_ANON_KEY=your-anon-key`
3. Run the app locally:
   `npm run dev`

If the Supabase variables are not configured, the app runs in offline mode using LocalStorage.
